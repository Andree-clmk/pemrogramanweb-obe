# Pemrograman Web - Proyek OBE

## Identitas Mata Kuliah
* **Mata Kuliah:** Pemrograman Web
* **Program Studi:** Sarjana Teknik Komputer UBT
* **Modul:** Modul Praktikum 2026

## Deskripsi Singkat Proyek
Proyek ini merupakan repositori awal dan latihan praktikum pemrogaman web berbasis *Outcome-Based Education* (OBE) untuk mengonfigurasi lingkungan lokal, struktur dokumen HTML dasar, serta pengelolaan version control menggunakan Git.

## Teknologi yang Digunakan
* **Web Server:** Laragon 5 (Apache)
* **Bahasa:** PHP 8.4[cite: 1], HTML5
* **Version Control:** Git & GitHub
* **Code Editor:** Visual Studio Code

## Cara Menjalankan Proyek Melalui Laragon 5
1. Buka aplikasi **Laragon 5** dan klik tombol **Start All**
2. Pastikan direktori proyek sudah berada di dalam folder `C:\laragon\www\pemrogramanweb-obe\`
3. Buka browser dan akses URL lokal: [http://localhost/pemrogramanweb-obe/](http://localhost/pemrogramanweb-obe/)
